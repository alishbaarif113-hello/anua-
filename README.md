## 🚀 How to Run Locally

### Option 1: Direct in Browser
Simply double-click `index.html` or open it with any web browser (Chrome, Edge, Safari, Firefox).

### Option 2: Using Node / npx (Recommended for Live Server)
In your terminal inside this folder:
```bash
npx serve .
# or
npx http-server .
```
Then visit `http://localhost:3000` or `http://localhost:8080`.

## 🌐 How to Publish / Deploy Online

### Deploy on Netlify (Fastest & Free)
1. Go to [netlify.com](https://www.netlify.com/) and sign in.
2. Drag and drop this entire folder (`word press`) into the Netlify dashboard.
3. Your site will be live instantly with a free `.netlify.app` domain and free SSL!

### Deploy on Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside this folder and follow the prompts.

### Deploy on GitHub Pages
1. Push this folder to a GitHub repository.
2. In GitHub, go to **Settings > Pages** and select `main` branch `/ (root)`.
3. Your site will be live on `https://<username>.github.io/<repo-name>/`.
